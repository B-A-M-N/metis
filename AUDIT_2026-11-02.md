## Architecture Verified

### Session Management ✅
- **Native PTY**: `pty_spawn.go`, `pty_supervise.go` - generation fencing, owner verification
- **Agent Discovery**: Three backends (tmux, PTY, native) unified in `metis_agents` MCP tool
- **Workspace Isolation**: Project root registration (`project_roots.go`), refusal on unregistered roots
- **Multiple Instances**: Session name as primary key, multiple instances in one directory supported

**Evidence**: Tests green, CAPABILITIES.md documents live qualification (echo provider, no paid inference)

---

### Terminal Experience ✅
- **Rendering**: Sanitized text snapshot, ANSI-stripped, 500ms refresh, non-blocking
- **Tab Switching**: Pure navigation state (`internal/tui/nav.go`), no cross-session bleeding
- **Input Delivery**: Lease-based authority (`input_leases` table), 30s TTL, conflict detection
- **Recovery**: Generation-fenced, stale/crashed session cleanup validated

**Evidence**: `TestBoundaryPaneBindingSingleWriter`, `TestRefreshSkipsWhileOneIsInFlight`

---

### Messaging & Communication ✅
- **Muse Messages**: `metis_muse_message` idempotent by request_id, returns turn_id promptly
- **M2M Bridge**: Stdin-only subprocess relay, fail-closed sender policy (`TestM2MBridgeKeepsSecretsOffArgv`)
- **Remote Access**: Fail-closed remote principal gate (`TestUnauthorizedMetisWriteRefused`)
- **State Sync**: Single-flight refresh coalescing, generation fencing prevents stale data

**Evidence**: F-18 fix verified, `TestRefreshApplyPreservesStaleMarker` green

---

### Security & Control ✅
- **Authentication**: Local operator = all operations; remote = explicit capability grant
- **Authorization**: `METIS_MCP_REMOTE_CAPABILITIES` + optional write token
- **Input Leases**: Single-writer enforcement at terminal boundary (AST boundary test mutation-proven)
- **Audit Trail**: `ops` command with filters, bounded JSONL sink, credential redaction

**Evidence**: F-02 fix (12 failing-first tests), `TestLeaseAuthority*` suite green
